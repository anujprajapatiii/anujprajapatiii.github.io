## A small information layer

Case studies often bury useful facts in paragraphs or spread them across
screenshots. This experiment borrows the clarity of nutrition labels and turns
it into a compact summary that can sit inside any project.

The format is deliberately flexible. A label can report measurable outcomes,
technical performance, or qualitative lessons without changing its structure.

## Three useful views

**Performance** keeps technical constraints legible. File size, interaction
time, main-thread work, dependencies, and the testing profile stay together.

**Impact** gives outcomes the same treatment. The numbers remain comparable
without becoming the whole story.

**Learnings** uses the structure without forcing metrics. It works as a short
record of the decisions worth carrying into the next project.

## Built for reuse

The label is a small React island inside an otherwise static Astro page. Its
content is typed data, its icons come from the site's existing Lucide package,
and every visual decision references the portfolio's semantic tokens.

That means the same component follows light and dark mode automatically, uses
the existing type and spacing scales, and can move between future project
themes without carrying a second design system with it.
